記事の書き方

2026-01-02 ／ 使い方

記事は、1記事につき1つの Markdown ファイルです。置き場所は content/posts/sample/ で、ファイル名は YYYY-MM-DD-<slug>.md の形にします。

先頭の情報（frontmatter）

ファイルの先頭に、その記事の情報を書きます。

---
title: 記事のタイトル
date: '2026-01-02'
category: 使い方
summary: 一覧に表示される短い要約
cover: sample/festival.webp
cover_alt: カバー画像の説明文
type: article
---
  • cover の画像は content/images/sample/ に置き、sample/<ファイル名> の形で指定します
  • slug は記事のURLの一部になります。半角英数字とハイフンで付けます

本文

本文は Markdown で書きます。見出しは ##、箇条書きは -、リンクは [文字](URL) です。

ページの埋め込み

自分のサイトの中にあるページ（ゲームなど）を記事の中でそのまま表示したいときは、embed と書いたコードブロックにURLを書きます。2行目に 幅x高さ を書くと、その比率で表示されます（省略すると 4:3 です）。3行目に 70% のように書くと、本文の幅に対する表示幅も指定できます。

```embed
https://（自分のサイト）/games/example/
960x720
70%
```

埋め込めるのは、自分のサイトと同じドメインのページだけです。外部サイトのURLを書いても表示されません。埋め込まれたページは、ダイアログを出したり、ページ全体を別のサイトへ移動させたり、フォームを送信したりできない形で表示されます。

書き終わったら GitHub に push してください。数分でサイトに反映されます。反映の途中でエラーがあれば、GitHub Actions のログに理由が出ます。
